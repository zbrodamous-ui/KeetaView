Your first request

After receiving your key, set KEETAVIEW_API_KEY privately in your server environment. Keep it out of browser code, URLs, screenshots, and source control.

This Node.js example makes one authenticated request. Run it on your server or local terminal with Node 24 or later.

const key = process.env.KEETAVIEW_API_KEY;
if (!key) throw new Error('Set KEETAVIEW_API_KEY privately first.');

const response = await fetch('https://keetaview.com/api/v1/status', {
  headers: { Authorization: `Bearer ${key}` },
  signal: AbortSignal.timeout(10000),
  redirect: 'error'
});
if (!response.ok) {
  throw new Error(`API returned ${response.status}`);
}
const { data } = await response.json();
console.log(data);

The status response reports network, historicalComplete, latestIndexedTimestamp, and coverageNote. The timestamp is the newest stored activity, not a guarantee of continuous coverage.

Four endpoints. One key.

Base URL: https://keetaview.com/api/v1. All endpoints use GET and return results in data.

Available beta endpoints

Work with transfer pages

  1. Request /transfers?token=FULL_TOKEN_ADDRESS&limit=20.
  2. Use the response’s nextBefore as before for the next request.
  3. Stop when nextBefore is null.

Pages follow insertion ID descending, not necessarily timestamp order. Backfill can add older activity with newer IDs; pages are not a frozen snapshot.

Amounts are exact raw-integer strings. Use token decimals and integer or decimal arithmetic; JavaScript Number can lose precision. Identify operations by block hash plus operation index.

Limits and recovery

30 requests per fixed UTC minute.
1,000 requests per UTC day, per key.

Authenticated requests count even when they return 400 or 404. Quota-rejected requests do not count.

  • 401: check whether the key is missing, invalid, or revoked.
  • 400: check request parameters.
  • 404: the block is absent from this index, or the route is unknown.
  • 429: wait for the Retry-After seconds before retrying.
  • 503: temporary service failure; retry later.

Remaining quotas appear in X-RateLimit-Remaining-Day and X-RateLimit-Remaining-Minute.
